Bring your people.
They bring their phones.

  1. 01

    Open a room

    Use the online test server or run Open Party Lab on your Windows PC. Put the host view on a shared screen.

  2. 02

    Scan & join

    Players scan the room’s QR code with their phones. Controllers run in the browser.

  3. 03

    Pick a game. Go.

    Try a quick drawing round, a bluffing game or a whole table of cards. Change games with the same group.

Two ways to get together.

01 / ONLINE

Take it for a spin.

Open the public test server and create a room. No local server setup required.

Try the online server ↗

The free test server may take about a minute to wake up. Rooms are temporary and can disappear after a restart.

02 / ON YOUR NETWORK

Host it yourself.

Download the Windows release, extract the complete ZIP and launch Open-Party-Lab.exe. Connect phones to the same Wi-Fi.

Download for Windows ↓

Node.js is bundled. Community builds are unsigned, so Windows may show a SmartScreen warning. Prefer running from source?

This is an actively developed project. Expect rough edges and unfinished games. Read the current project status ↗
